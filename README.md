# Java Programming Tasks

This repository contains two Java programming projects completed as part of my Java programming assignment.

## Task 1: Student Grade Tracker

### Description
The Student Grade Tracker is a Java application that allows users to manage student grades. It stores student marks, calculates statistics, and displays a summary report.

### Features
- Add student names and grades
- Store data using Arrays or ArrayList
- Calculate:
  - Average score
  - Highest score
  - Lowest score
- Display a summary report
- Console-based user interface

### Technologies Used
- Java
- ArrayList
- Object-Oriented Programming (OOP)

## Task 2: Artificial Intelligence Chatbot

### Description
The AI Chatbot is a Java application that simulates conversations with users by answering frequently asked questions. It uses rule-based logic (or NLP if implemented) to generate responses.

### Features
- Interactive chat interface
- Rule-based responses
- Frequently Asked Questions (FAQ) support
- Basic Natural Language Processing (NLP)
- Easy to extend with more responses
- GUI interface

### Technologies Used
- Java
- String Processing
- Collections Framework
- Object-Oriented Programming (OOP)
